Help with designing and exporting your App Store screenshots.

Screenshot Studio Pro turns raw app screenshots into finished App Store artwork: drop a capture in, put it in a device frame on a styled background, add a headline, and export at the exact pixel sizes App Store Connect expects.

Getting Started

  • Add your captures. Drag screenshots onto the canvas, or use Add Screenshot. Dropping several at once creates one screen per image and picks the matching device automatically.
  • Pick a look. Choose a template or gradient in the inspector, then adjust the background, headline, and device placement. "Match Colors to Screenshot" pulls a palette out of your own artwork.
  • Check before you upload. The preflight button flags low text contrast, headlines that are too long, screens with no image, and sets that exceed Apple's ten-screenshot limit.
  • Export. Choose Folders or fastlane layout, then Export All. Files are named and sized for direct upload.

Troubleshooting

  • Export fails, or the default folder stops working. macOS grants the app access to the folder you pick. If the folder was moved, renamed, deleted, or lives on a drive that is no longer connected, that access no longer resolves and the app will ask you to choose a folder again. To set a new default, open Settings → Defaults & Files → Export Destination Folder.
  • My screenshot looks cropped or stretched inside the frame. The capture's shape does not match the device you selected. Either switch the device in the inspector, or use the screenshot zoom and offset controls to reframe it inside the screen. Preflight warns when a capture is more than 12% away from the device's aspect ratio.
  • Where did my exported dark-mode images go? Dark variants are only exported for screens that actually have a dark screenshot assigned. In Folders layout they go into Light and Dark subfolders. In fastlane layout they stay in the locale folder with a _dark suffix, so the structure stays valid for fastlane deliver.
  • Translations. "Copy Base Texts Into…" fills empty fields with your base-language wording so you can see the layout — it does not translate. For real translations, use Export Texts for Translation… to get a CSV, have it translated, then Import Translated Texts…. You can also import an Xcode String Catalog.
  • Moving a project to another Mac. Use Save Project…. The saved file embeds every image the project uses, so it opens complete on the other machine. Opening a project replaces whatever you currently have open, so save first if you want to keep it.
  • Undo. Command-Z steps back through your design changes. The app also saves your work automatically every few seconds.
